Mock Provider
之後換 OpenAI API

教師自訂病例、學生 session 與完成紀錄目前都儲存在同一瀏覽器的 localStorage，因此適合 POC 展示，但不適合多人正式教學。正式版會把這些資料搬到 PostgreSQL / Neon，並加入教師／學生登入與權限。

目前自訂病例定義會存在瀏覽器端，技術上學生可透過開發者工具查看；正式版病例真值必須只存在伺服器端。
